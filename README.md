# Phone Control

אפליקציית Android המשמשת כמסך בית חלופי, עם מגירת אפליקציות וחיפוש בעברית.

## מה כלול
- בחירה ב-Phone Control כמסך הבית (Launcher) של המכשיר.
- החלקה למעלה במסך הבית לפתיחת כל האפליקציות.
- חיפוש בזמן אמת וכפתור X לניקוי החיפוש.
- פתיחת אפליקציה בלחיצה על הסמל.
- אפשרות לנעול את המסך בהקשה כפולה על אזור ריק במסך הבית, לאחר הפעלת שירות הנגישות.

## מגבלות Android
אפליקציה רגילה אינה יכולה להדליק מסך כבוי באמצעות הקשה כפולה. יש להפעיל את האפשרות המובנית של יצרן המכשיר, אם קיימת (למשל Double tap to wake). אין כאן עקיפת הרשאות מערכת.

## בנייה
פתח את הפרויקט ב-Android Studio ובצע Gradle Sync ואז Build > Build APK(s).

דרישות: Android Gradle Plugin 8.6.1, Kotlin 2.0.21, JDK 17, Android SDK 35.
